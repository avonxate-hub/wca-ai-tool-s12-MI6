# Duka Stock Advisor Demo Guide

## Purpose

This guide helps demonstrate the main features of the Duka Stock Advisor during the live presentation.

## 1. Start a New Session

From the main menu, select:

1. Start New Session

Enter realistic stock information.

Example:

"I have 10 bags of unga and 8 bottles of cooking oil."

## 2. Demonstrate Conversation Memory

Continue with information from the previous message.

Example:

"I sold 4 bags of unga and 3 bottles of cooking oil today."

Then ask:

"Should I start preparing to restock?"

The AI should use information from earlier messages when responding.

## 3. Demonstrate 4+ Turns

Use at least four user messages during the demonstration.

The purpose is to show that the application maintains conversation history.

## 4. Demonstrate Error Handling

Test an empty input or invalid menu option.

The application should display a clear message instead of crashing.

The team can also demonstrate the invalid JSON retry mechanism if appropriate.
